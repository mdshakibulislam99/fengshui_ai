## API Usage (cURL)

```bash
curl -X POST http://localhost:3000/api/personal-feng-shui/analyze \
  -H "Content-Type: application/json" \
  -d '{
    "profile": {
      "birthYear": 1990,
      "gender": "male",
      "birthMonth": 6,
      "goals": ["career", "wealth", "health"],
      "preferredDirection": "N",
      "budget": "medium"
    }
  }'
```

## Input Fields

REQUIRED:
- birthYear (int): 1900-2026
- gender (string): "male" or "female"

OPTIONAL:
- birthMonth (int): 1-12 (enables Ba Zi analysis)
- birthDay (int): 1-31
- goals (array): ["career", "wealth", "health", "relationships", "recognition"]
- preferredDirection (string): "N", "NE", "E", "SE", "S", "SW", "W", "NW"
- budget (string): "low", "medium", "high"

## Example Integration (JavaScript)

```javascript
async function getPersonalFengShui(profile) {
    const response = await fetch('/api/personal-feng-shui/analyze', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ profile })
    });
    
    const { success, data } = await response.json();
    
    if (success) {
        console.log(`Your Kua Number: ${data.personal_profile.kua_number}`);
        console.log(`Best Direction: ${data.directions.best_direction}`);
        console.log(`Recommendations: ${data.recommendations.length}`);
        return data;
    }
}

// Usage
const result = await getPersonalFengShui({
    birthYear: 1990,
    gender: 'male',
    goals: ['career', 'health']
});
```

**No goals provided**:
- Uses default general recommendations
